\# 已知问题与改进计划 (Known Issues)



1\. \*\*内存碎片风险\*\*：目前使用 Arduino 的 `String` 类拼接 JSON 数据，在长时间运行下可能存在内存碎片风险。\*\*改进计划\*\*：后续将替换为 C 语言原生的 `snprintf` 和定长字符数组。

2\. \*\*断网数据丢失\*\*：目前断网后数据直接丢弃，未实现本地缓存。\*\*改进计划\*\*：计划引入环形缓冲区（Ring Buffer），在网络恢复后实现断网数据的补传。

3\. \*\*仿真环境局限\*\*：目前基于 Wokwi 仿真，无法完全模拟真实硬件中的信号干扰、接触不良等物理问题。\*\*改进计划\*\*：后续采购实物开发板进行实机联调验证。
