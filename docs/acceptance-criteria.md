# 项目验收清单 (V1-V5必做)

| 编号 | 验收项 | 验收证据 | 目标值 |
|---|---|---|---|
| V1 | OLED 显示温湿度 | Wokwi 仿真截图/录屏 | 每 2 秒刷新 |
| V2 | 串口打印传感器数据 | 串口监视器日志截图 | 格式 `T=25 H=60` |
| V3 | 数据上云 | MQTTX 订阅截图 | 每 5 秒一条发往 `home/env` |
| V4 | 远程控制 | 录屏：发送指令，LED亮灭 | 延迟 < 2 秒 |
| V5 | 断线重连 | Wokwi 运行日志 | 断网 10 秒，恢复 < 15 秒 |

## 明确“不做什么”清单
- 第一版绝对不画 PCB 板。
- 第一版绝对不开发手机原生 APP（用 MQTTX 或网页端替代）。
- 第一版不接入真实的云平台（先用公共 Broker 测通）。
